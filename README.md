# **TestTask**

Тестовый проект, созданный на Unity *2022.3.12*.

## **Описание**
Проект демонстрирует базовые игровые механики:
- Передвижение персонажа  
- Генерация карты и препятствий  
- Система боя (fighting) с врагами  
- Механика открытия сундука  

## **Запуск проекта**
1. Установите Unity версии *2022.3.12* или выше.  
2. Клонируйте или скачайте репозиторий.  
3. Откройте проект в Unity Hub.  
4. Запустите сцену `EntryPointBootstrap` для старта игры.  

## **Игровые механики**
- **Передвижение персонажа**: реализовано через систему событий и анимации.  
- **Генерация карты**: динамическое создание дорог, препятствий и финальной точки.  
- **Препятствия**: при столкновении персонаж теряет возможность двигаться и проигрывает анимацию смерти.  
- **Бой с врагами**: реализован через систему событий и Addressables.  
- **Сундук**: открывается при выполнении условий, добавляя элемент прогрессии.  

## **Технологии**
- **Unity *2022.3.12***  
- **Zenject** — внедрение зависимостей  
- **UniRx** — реактивные события  
- **DOTween** — анимации и твины  
- **Addressables** — управление ресурсами
